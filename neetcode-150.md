## Main Hints

The crux of each problem, so the idea comes back quickly.

### Arrays & Hashing

- **Contains Duplicate**: Put items in a set; a repeat means duplicate.
- **Valid Anagram**: Compare character counts (Counter or 26-array).
- **Two Sum**: Hash map of value -> index; look up `target - x` as you go.
- **Group Anagrams**: Hash key = sorted word or 26-count tuple.
- **Top K Frequent Elements**: Count, then bucket sort by frequency (index = count) for O(n).
- **Encode and Decode Strings**: Length-prefix each string: `len#str`, so delimiters in the data don't matter.
- **Product of Array Except Self**: Prefix product pass, then suffix product pass; no division.
- **Valid Sudoku**: Sets per row, column and 3x3 box (box = `(r//3, c//3)`).
- **Longest Consecutive Sequence**: Set; only start counting from numbers where `n-1` is absent.

### Two Pointers

- **Valid Palindrome**: Pointers from both ends, skipping non-alphanumerics.
- **Two Sum II - Input Array Is Sorted**: Sorted: sum too big -> move right pointer left, too small -> move left right.
- **3Sum**: Sort, fix one number, two-pointer the rest; skip duplicates.
- **Container With Most Water**: Move the pointer at the shorter wall; width shrinks so only a taller wall can help.
- **Trapping Rain Water**: Water at i = min(maxLeft, maxRight) - h[i]; two pointers track the smaller side's max.

### Sliding Window

- **Best Time to Buy and Sell Stock**: Track min price so far; best = max(price - min).
- **Longest Substring Without Repeating Characters**: Window + set/last-index map; shrink left on repeat.
- **Longest Repeating Character Replacement**: Valid if `window - maxFreq <= k`; maxFreq never needs to decrease.
- **Permutation in String**: Fixed window of len(s1); compare char counts.
- **Minimum Window Substring**: Expand until all needed chars are covered (`have == need`), then shrink to minimize.
- **Sliding Window Maximum**: Monotonic decreasing deque of indices; front is the max.

### Stack

- **Valid Parentheses**: Push openers; a closer must match the top.
- **Min Stack**: Store `(val, minSoFar)` on each push.
- **Evaluate Reverse Polish Notation**: Push numbers; on operator pop two (order matters for `-` and `/`).
- **Generate Parentheses**: Backtrack: add `(` if open < n, add `)` if close < open.
- **Daily Temperatures**: Monotonic decreasing stack of indices; pop when a warmer day arrives.
- **Car Fleet**: Sort by position descending; compute arrival times; a slower car ahead absorbs those behind.
- **Largest Rectangle in Histogram**: Monotonic increasing stack; popped bar's width extends back to its start index.

### Binary Search

- **Binary Search**: Standard lo/hi/mid loop.
- **Search a 2D Matrix**: Treat as flat sorted array: `row = mid // cols`, `col = mid % cols`.
- **Koko Eating Bananas**: Binary search the answer (speed); check feasibility with ceil-sum of hours.
- **Find Minimum in Rotated Sorted Array**: Compare mid to right: if `nums[mid] > nums[hi]` min is right, else left (incl. mid).
- **Search in Rotated Sorted Array**: One half is always sorted; check if target lies in it, else go other way.
- **Time Based Key-Value Store**: Per-key list of (timestamp, value); binary search for the last timestamp <= query.
- **Median of Two Sorted Arrays**: Binary search the partition of the smaller array so left halves <= right halves.

### Linked List

- **Reverse Linked List**: Keep `prev`, `cur`; flip `cur.next` while advancing.
- **Merge Two Sorted Lists**: Dummy head; append the smaller node each step.
- **Reorder List**: Find middle (slow/fast), reverse second half, interleave.
- **Remove Nth Node From End of List**: Fast pointer n ahead, then move both; dummy head handles removing the first node.
- **Copy List with Random Pointer**: Map old node -> new node; two passes (create, then wire next/random).
- **Add Two Numbers**: Digit-by-digit with carry; keep going while carry remains.
- **Linked List Cycle**: Floyd's: slow +1, fast +2; they meet iff cycle.
- **Find the Duplicate Number**: Treat values as next pointers -> Floyd's cycle; second phase finds the entrance.
- **LRU Cache**: Hash map + doubly linked list (or OrderedDict); move to front on access, evict tail.
- **Merge k Sorted Lists**: Min-heap of heads, or divide-and-conquer pairwise merges.
- **Reverse Nodes in k-Group**: Check k nodes exist, reverse that segment, reconnect with the previous group's tail.

### Trees

- **Invert Binary Tree**: Swap children recursively.
- **Maximum Depth of Binary Tree**: `1 + max(depth(left), depth(right))`.
- **Diameter of Binary Tree**: At each node, `leftH + rightH`; track global max while returning height.
- **Balanced Binary Tree**: Return height, with a sentinel (-1) if any subtree is unbalanced.
- **Same Tree**: Recurse on both trees in lockstep; both-null is true.
- **Subtree of Another Tree**: At each node of root, run Same Tree against subRoot.
- **Lowest Common Ancestor of a Binary Search Tree**: Walk down: both smaller -> left, both larger -> right, else current is LCA.
- **Binary Tree Level Order Traversal**: BFS; process `len(queue)` nodes per level.
- **Binary Tree Right Side View**: BFS, take the last node of each level.
- **Count Good Nodes in Binary Tree**: DFS carrying max-so-far; good if `val >= max`.
- **Validate Binary Search Tree**: DFS with (low, high) bounds, not just parent comparison.
- **Kth Smallest Element in a BST**: Inorder traversal gives sorted order; stop at k.
- **Construct Binary Tree from Preorder and Inorder Traversal**: Preorder[0] is root; its index in inorder splits left/right sizes.
- **Binary Tree Maximum Path Sum**: Return best downward path (clamped at 0); update global with `left + right + val`.
- **Serialize and Deserialize Binary Tree**: Preorder with null markers; rebuild with an iterator.

### Heap / Priority Queue

- **Kth Largest Element in a Stream**: Min-heap of size k; top is the kth largest.
- **Last Stone Weight**: Max-heap (negate values in Python); smash top two.
- **K Closest Points to Origin**: Heap on squared distance (no sqrt needed).
- **Kth Largest Element in an Array**: Size-k min-heap, or quickselect for O(n) average.
- **Task Scheduler**: Max-heap + cooldown queue; or formula `(maxFreq-1)*(n+1) + countOfMax`.
- **Design Twitter**: Per-user tweet lists + follow sets; merge recent tweets with a heap.
- **Find Median from Data Stream**: Two heaps: max-heap for lower half, min-heap for upper; keep sizes balanced.

### Backtracking

- **Subsets**: For each index: include or skip.
- **Combination Sum**: Reuse allowed: recurse on same index after picking; stop when sum exceeds target.
- **Permutations**: Track used elements (or swap in place).
- **Subsets II**: Sort; skip a value equal to the previous at the same recursion level.
- **Combination Sum II**: Sort; each number once; skip duplicates at the same level.
- **Word Search**: DFS from each cell; mark visited, unmark on backtrack.
- **Palindrome Partitioning**: Try every prefix that's a palindrome, recurse on the rest.
- **Letter Combinations of a Phone Number**: Digit -> letters map; recurse by digit position.
- **N-Queens**: Place row by row; sets for columns, diag (`r-c`), anti-diag (`r+c`).

### Tries

- **Implement Trie (Prefix Tree)**: Node = children dict + end flag.
- **Design Add and Search Words Data Structure**: On `.`, recurse into every child.
- **Word Search II**: Build a trie of words; one DFS over the grid, prune trie branches once found.

### Graphs

- **Number of Islands**: DFS/BFS flood fill, count starts.
- **Max Area of Island**: Flood fill returning area.
- **Clone Graph**: DFS with map old -> clone to handle cycles.
- **Walls and Gates**: Multi-source BFS from all gates.
- **Rotting Oranges**: Multi-source BFS by minute; check no fresh remain.
- **Pacific Atlantic Water Flow**: Reverse: BFS/DFS uphill from each ocean's border; intersect the sets.
- **Surrounded Regions**: Mark O's reachable from the border as safe; flip the rest.
- **Course Schedule**: Cycle detection in a directed graph (DFS states or Kahn's).
- **Course Schedule II**: Topological order (Kahn's); empty if cycle.
- **Graph Valid Tree**: Valid iff `edges == n-1` and connected (union-find or DFS).
- **Number of Connected Components in an Undirected Graph**: Union-find, decrement count on each successful union.
- **Redundant Connection**: Union-find; the edge whose endpoints already share a root.
- **Word Ladder**: BFS; neighbors via wildcard patterns (`h*t`) buckets.

### Advanced Graphs

- **Reconstruct Itinerary**: Hierholzer's: DFS on sorted edges, post-order append, reverse.
- **Min Cost to Connect All Points**: MST: Prim's with heap or Kruskal's with union-find.
- **Network Delay Time**: Dijkstra; answer is max distance (or -1 if unreachable).
- **Swim in Rising Water**: Dijkstra/min-heap where cost = max elevation on path.
- **Alien Dictionary**: Edges from first differing char of adjacent words; topo sort; watch prefix-invalid case.
- **Cheapest Flights Within K Stops**: Bellman-Ford limited to k+1 rounds (copy the distance array each round).

### 1-D Dynamic Programming

- **Climbing Stairs**: Fibonacci: `dp[i] = dp[i-1] + dp[i-2]`.
- **Min Cost Climbing Stairs**: `dp[i] = cost[i] + min(dp[i-1], dp[i-2])`.
- **House Robber**: `rob = max(prev2 + n, prev1)`.
- **House Robber II**: Circle: run House Robber on `nums[1:]` and `nums[:-1]`.
- **Longest Palindromic Substring**: Expand around each center (odd and even).
- **Palindromic Substrings**: Same expand-around-center, count each success.
- **Decode Ways**: `dp[i]` from 1-digit (non-zero) and 2-digit (10-26) endings.
- **Coin Change**: `dp[a] = 1 + min(dp[a - c])`; unreachable = inf.
- **Maximum Product Subarray**: Track both running max and min (negatives flip them).
- **Word Break**: `dp[i]` true if some `dp[j]` true and `s[j:i]` in dict.
- **Longest Increasing Subsequence**: O(n^2) dp, or patience sorting with bisect for O(n log n).
- **Partition Equal Subset Sum**: 0/1 knapsack for target = sum/2 (odd sum -> false).

### 2-D Dynamic Programming

- **Unique Paths**: `dp[r][c] = dp[r-1][c] + dp[r][c-1]` (or combinatorics).
- **Longest Common Subsequence**: Match -> `1 + dp[i-1][j-1]`, else max of up/left.
- **Best Time to Buy and Sell Stock with Cooldown**: State machine: held / sold / rest.
- **Coin Change II**: Count combinations: coins in the outer loop, amounts inner.
- **Target Sum**: DP over (index, running sum) with memo, or subset-sum reduction.
- **Interleaving String**: `dp[i][j]`: s3[i+j] matches s1[i] or s2[j].
- **Longest Increasing Path in a Matrix**: DFS + memo per cell (no visited needed since strictly increasing).
- **Distinct Subsequences**: On match: use it + skip it; on mismatch: skip.
- **Edit Distance**: Match -> diagonal; else 1 + min(insert, delete, replace).
- **Burst Balloons**: Interval DP; pick the LAST balloon to burst in (l, r).
- **Regular Expression Matching**: Handle `*` as zero-or-more of previous: skip pair, or consume a char if it matches.

### Greedy

- **Maximum Subarray**: Kadane: reset running sum when it goes negative.
- **Jump Game**: Track farthest reachable index; fail if i exceeds it.
- **Jump Game II**: BFS-by-levels greedy: extend the window to the farthest reach.
- **Gas Station**: If total gas >= total cost a solution exists; restart start after any negative tank.
- **Hand of Straights**: Counter + min-heap; always start a group at the smallest remaining card.
- **Merge Triplets to Form Target Triplet**: Ignore triplets exceeding target in any slot; check each target slot is hit.
- **Partition Labels**: Last index per char; cut when i reaches the current window end.
- **Valid Parenthesis String**: Track range [lo, hi] of possible open counts; `*` widens it.

### Intervals

- **Insert Interval**: Add the ones before, merge the overlapping, add the ones after.
- **Merge Intervals**: Sort by start; merge when `start <= lastEnd`.
- **Non-overlapping Intervals**: Sort by start; on overlap, drop the one with the larger end.
- **Meeting Rooms**: Sort; any overlap with the previous -> false.
- **Meeting Rooms II**: Sort starts and ends separately (two pointers) or min-heap of end times.
- **Minimum Interval to Include Each Query**: Sort queries; sweep intervals into a min-heap keyed by size, pop expired ones.

### Math & Geometry

- **Rotate Image**: Transpose, then reverse each row.
- **Spiral Matrix**: Shrink top/bottom/left/right boundaries; guard against single row/col.
- **Set Matrix Zeroes**: Use first row/col as markers (track their own zero-ness separately).
- **Happy Number**: Detect the cycle with a set or Floyd's.
- **Plus One**: Walk from the end; 9 -> 0 and carry, else increment and return.
- **Pow(x, n)**: Fast exponentiation (square, halve n); handle negative n.
- **Multiply Strings**: Grade-school: `res[i+j+1] += a*b`, then carry.
- **Detect Squares**: Count points; for each diagonal point, multiply counts of the two other corners.

### Bit Manipulation

- **Single Number**: XOR all; pairs cancel.
- **Number of 1 Bits**: `n &= n - 1` clears the lowest set bit.
- **Counting Bits**: `dp[i] = dp[i >> 1] + (i & 1)`.
- **Reverse Bits**: Shift result left, OR in the lowest bit of n, shift n right; 32 times.
- **Missing Number**: XOR indices with values, or `n(n+1)/2 - sum`.
- **Sum of Two Integers**: XOR = sum without carry; `(a & b) << 1` = carry; mask to 32 bits in Python.
- **Reverse Integer**: Pop digit/push digit; check 32-bit overflow before the push.
